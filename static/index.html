How Quadratic Lab Works

  1. Your browser requests /api/solve. Python chooses a nonzero a and random b and c.
  2. The server calculates the discriminant and real roots, returning its hostname and IP address with the result.
  3. The browser plots the curve, vertex, symmetry axis, and real roots. Use +, −, or ⟲ to adjust the graph.

Press ⌘/Ctrl + Enter for a new equation. Request time measures the browser’s full round trip, not only computation.
